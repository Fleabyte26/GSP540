## Known lab traps/bugs (read first)

1. Location must be `global` in every .env file. A region name here makes the agents fail.
2. Do not create API keys. The lab wants Agent Platform through the .env files only.
3. Three checkpoints (Tasks 2, 3 and 5) only pass after you really chat with the agent. Editing the files is not enough.
4. If `adk` gives "command not found" (this can happen in a new Cloud Shell tab), run the PATH line from the lab's Task 1 again, then repeat the block.
5. Stop the web server with CTRL+C before you paste the next block, or the paste goes into the running server.
6. If the Dev UI shows an error, click + New Session (top right) and ask again.
7. Do the lab's download and unzip step from your home folder (`cd ~` first). Every block here expects the project at ~/adk_project.
8. If the Dev UI shows "No API key was provided", the .env files are missing. Stop the server with CTRL+C, paste the Setup block again, restart `adk web` and click + New Session.
9. In Task 5 the agent list also shows the sub-agents (llm_auditor.sub_agents...). Select plain `llm_auditor` only.
10. The checker lags. Wait 30-60 seconds and click Check my progress again.

## Task 2. Initialize and Configure the Travel Scout

Paste this block. It gives the agent the google_search tool.

```bash
cd ~/adk_project
cp my_google_search_agent/agent.py my_google_search_agent/agent.py.bak
cat > ~/p2.py <<'EOF'
import re, pathlib
p = pathlib.Path("my_google_search_agent/agent.py")
s = p.read_text()
def code(t):
    return "\n".join(l for l in t.splitlines() if not l.lstrip().startswith("#"))
s = re.sub(r"(?m)^[ \t]*#[ \t]*(from google\.adk\.tools.* import .*google_search.*)", r"\1", s)
if not re.search(r"import .*\bgoogle_search\b", code(s)):
    s = "from google.adk.tools import google_search\n" + s
s = re.sub(r"(?m)^([ \t]*)#[ \t]*(tools[ \t]*=[ \t]*\[[ \t]*google_search[ \t]*\].*)", r"\1\2", s)
s = re.sub(r"tools[ \t]*=[ \t]*\[[ \t]*\]", "tools=[google_search]", s)
if not re.search(r"\btools[ \t]*=", code(s)):
    s = re.sub(r"\b((?:Llm)?Agent\()", r"\1\n    tools=[google_search],", s, count=1)
p.write_text(s)
EOF
python3 ~/p2.py
python3 -m py_compile my_google_search_agent/agent.py && grep -n 'google_search' my_google_search_agent/agent.py
```

You should see an import line with google_search and a line with `tools=[google_search]`, and no error.

## Task 4. Enforce structured standards

Paste this block. It adds the CountryCapital model, the output schema, the two transfer settings and the model name.

```bash
cd ~/adk_project
cp geo_validator/agent.py geo_validator/agent.py.bak
cat > ~/p4.py <<'EOF'
import ast, re, pathlib
p = pathlib.Path("geo_validator/agent.py")
s = p.read_text()
model = (pathlib.Path.home() / "model").read_text().strip()
def code(t):
    return "\n".join(l for l in t.splitlines() if not l.lstrip().startswith("#"))
s = re.sub(r"([\"'])gemini-[\w.\-]+([\"'])", lambda m: m.group(1) + model + m.group(2), s)
add = []
for a, v in [("output_schema", "CountryCapital"), ("disallow_transfer_to_parent", "True"), ("disallow_transfer_to_peers", "True")]:
    if re.search(r"\b" + a + r"[ \t]*=", code(s)):
        s = re.sub(r"(?m)^(?![ \t]*#)(.*\b" + a + r"[ \t]*=[ \t]*)[\w.]+", lambda m: m.group(1) + v, s)
    else:
        add.append("    " + a + "=" + v + ",")
if add:
    s = re.sub(r"\b((?:Llm)?Agent\()", lambda m: m.group(1) + "\n" + "\n".join(add), s, count=1)
if not re.search(r"(?m)^class CountryCapital\b", s):
    last = max([n.end_lineno for n in ast.parse(s).body if isinstance(n, (ast.Import, ast.ImportFrom))] or [0])
    lines = s.splitlines()
    lines[last:last] = ["from pydantic import BaseModel", "", "", "class CountryCapital(BaseModel):", "    capital: str", ""]
    s = "\n".join(lines) + "\n"
p.write_text(s)
EOF
python3 ~/p4.py
python3 -m py_compile geo_validator/agent.py && grep -n -A1 'CountryCapital\|disallow_transfer\|gemini' geo_validator/agent.py
```

You should see `class CountryCapital(BaseModel):` with `capital: str` under it, `output_schema=CountryCapital`, both disallow_transfer lines set to True, and no error.

Run the agent:

```bash
cd ~/adk_project
python3 geo_validator/agent.py
```

You should see a JSON object such as {"capital": "Paris"}, not a sentence.

## Task 5. Deploy the Brochure Auditor

Paste this block. It turns the reviser_agent back on.

```bash
cd ~/adk_project
cp llm_auditor/agent.py llm_auditor/agent.py.bak
cat > ~/p5.py <<'EOF'
import re, pathlib
p = pathlib.Path("llm_auditor/agent.py")
s = p.read_text()
def code(t):
    return "\n".join(l.split("#")[0] for l in t.splitlines())
s = re.sub(r"(?m)^([ \t]*)#[ \t]*((?:from|import)\b.*\breviser.*)", r"\1\2", s)
s = re.sub(r"(?m)^([ \t]*)#[ \t]*(reviser_agent[ \t]*,?[ \t]*\]?.*)", r"\1\2", s)
s = re.sub(r"(?m)^([ \t]*)#[ \t]*(sub_agents[ \t]*=.*reviser_agent.*)", r"\1\2", s)
if not re.search(r"import .*\breviser_agent\b", code(s)):
    s = "from .sub_agents.reviser import reviser_agent\n" + s
m = re.search(r"sub_agents[ \t]*=[ \t]*\[([^\]]*)\]", code(s))
if m and "reviser_agent" not in m.group(1):
    s = re.sub(r"(sub_agents[ \t]*=[ \t]*\[[^\]]*?critic_agent)[ \t]*,?", r"\1, reviser_agent,", s, count=1)
p.write_text(s)
EOF
python3 ~/p5.py
python3 -m py_compile llm_auditor/agent.py && grep -n 'reviser' llm_auditor/agent.py
```

You should see an import line for reviser_agent with no # in front, and reviser_agent inside the sub_agents list, and no error.
